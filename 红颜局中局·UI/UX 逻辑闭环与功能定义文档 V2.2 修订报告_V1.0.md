## 2. 核心逻辑修正与闭环

### 2.1 定位修正：伴随型导航
*   **调整**：引入“底部 Tab 栏 + 深度链接直达”的双层导航体系。
*   **首页场景感知**：首页将区分“直播中”和“非直播”两种形态。直播中优先展示“当前环节（如：为3号选手集赞）”和“进入直播间”按钮。

### 2.2 交互逻辑去伪存真
*   **修正**：移除小程序内的“点赞/送礼”按钮。
*   **新方案**：小程序仅作为数据展示和权益核销工具。详情页按钮改为“**去直播间支持**”（跳转直播间）和“**购买应援周边**”（跳转小黄车）。

### 2.3 卡密核销与数字写真语义
*   **卡密**：一次性使用，核销即失效。
*   **写真**：用户永久拥有，核销后自动存入“我的写真收藏”模块，拒绝“阅后即焚”。
*   **自动填入**：若阿奇索不支持参数链接，核销页将强化“**自动检测剪贴板**”功能，实现一键粘贴。

### 2.4 补全“卧底之夜”体验
*   **新增**：针对周一直播，新增“卧底视频轮播”和“卧底之王投票”页面，确保周一直播时小程序有对应的互动界面。

### 2.5 实时数据同步
*   **技术路径**：首页“当前环节”和人气看板将采用 **WebSocket 或 1s 频率的长轮询**，确保场控后台切换选手的瞬间，前端能在 2 秒内同步。

## 3. 给彬少的 UI 设计建议 (基于 Claude 意见)

1.  **Tab 栏设计**：[首页]、[选手]、[人气]、[我的]。
2.  **合规红线**：选手列表严禁按人气排序，统一按序号排列。
3.  **状态设计**：每个页面必须包含“加载中、空数据、错误/断线”三套状态。
4.  **核销仪式感**：核销成功页要突出“为X号选手贡献了XX人气值”的反馈感。
