## 三、补证方案：严格只走 A / B 两条路径

### 方案 A：字段或隐藏字段管理面板（首选）

先在**正式交付版**智能表格中查找腾讯文档官方的“字段”或“隐藏字段”管理面板。若面板显示全部字段名的文本列表，则仅截取一张能覆盖全部 21 个字段名的截图；该截图将与源 Excel 的 21 个字段名逐字比对。

> **停止条件：**若该入口不存在、界面名称不匹配、面板未展示全部字段名，立即截图报告，然后只切换到方案 B；不自行寻找第三条路径。

### 方案 B：导出交付版 Excel 后程序化比对（兜底）

仅在方案 A 无法完成时，从**正式交付版智能表格**导出 Excel。对“导出的交付版 Excel”与“用户原始 Excel”的列名、列顺序、列数进行逐字程序化比较。若一致，则将导出 Excel 与比较结果上传公开仓库供 Claude 独立复核。

> **授权边界：**虽然当前表仅含样例行，但导出 Excel 并上传到**公开** GitHub 属于新增公开范围。执行方案 B 前需 John 明确授权公开该导出文件；未获授权时，不导出、不上传。
