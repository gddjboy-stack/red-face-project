## 四、蓝军说明与待审查点

C2 中 `StatsMapper.ensurePlayerRoundStats()` 使用 `INSERT ... ON DUPLICATE KEY UPDATE player_id = player_id` 确保统计行存在，随后严格使用 `UPDATE ... SET individual_popularity = individual_popularity + ?` 累加写法更新统计值。这一实现是为了同时满足“首次写入可创建统计行”和“第 4 步必须累加更新，禁止先 SELECT 再 SET”的要求。请 Claude 重点审查该写法是否符合手册对并发安全的约束。

C2 仅实现 `player` 直接归属。若 `targetType` 为空，目前会调用 `collectStateService.getCurrent()` 后抛出 `UnsupportedOperationException`，以明确阻止 C2 越界处理 `like/comment` 的场控归属。该部分将在 C3 按任务卡实现。
