# C6 任务卡提交报告 - TokenGeneratorService 实现

## 1. 任务概述

本任务卡旨在实现 `TokenGeneratorService`，提供卡密批量生成、唯一性保证、入库和纯文本导出功能。同时，需要提供相应的 JUnit 测试和导出样例。

## 2. 需求分析与设计

### 2.1 功能点

*   **卡密批量生成**: 根据指定数量、玩家ID、积分、写真资产ID和产品SKU生成卡密。
*   **唯一性保证**: 生成的每个卡密必须是唯一的。
*   **卡密格式**: 卡密应遵循 `RFZJ-XXXX-XXXX-XXXX` 的格式，其中 `RFZJ` 为前缀，`XXXX` 为随机字符段，总长度为 19 位。
*   **入库**: 生成的卡密需存储到数据库中，包含 `tokenId`、`playerId`、`points`、`photoAssetId`、`productSku`、`aqisoBatchId`、`status` 和 `createdAt` 等字段。
*   **纯文本导出**: 根据批次 ID 导出该批次所有卡密，每行一个卡密。

### 2.2 关键技术点

*   **Spring Data JPA**: 用于数据库操作，包括实体定义、Repository 接口。
*   **UUID/随机数生成**: 用于生成卡密随机段，并结合唯一性检查机制。
*   **事务管理**: 确保卡密生成和入库的原子性。
*   **单元测试**: 使用 JUnit 和 Mockito 对服务层逻辑进行充分测试。

## 3. 实现细节

### 3.1 `AppConstants.java` 更新

在 `AppConstants.java` 中定义了卡密相关的常量，包括前缀、字符集、随机段长度、随机段数量和总长度。其中 `TOKEN_TOTAL_LENGTH` 修正为 19。

```java
public final class AppConstants {
    // ... 其他常量
    public static final String TOKEN_PREFIX = "RFZJ";
    public static final String TOKEN_CHARSET = "23456789ABCDEFGHJKMNPQRSTUVWXYZ";
    public static final int TOKEN_SECTION_LENGTH = 4;
    public static final int TOKEN_SECTION_COUNT = 3;
    public static final int TOKEN_TOTAL_LENGTH = 19; // RFZJ-XXXX-XXXX-XXXX = 4 + 3*4 + 3 (hyphens) = 19
}
```

### 3.2 `Token` 实体类

创建 `Token` 实体类，使用 `@Entity` 和 `@Table` 注解映射到数据库的 `tokens` 表。`tokenId` 作为主键，并包含其他业务字段。

```java
@Entity
@Table(name = "tokens")
public class Token {
    @Id
    @Column(name = "token_id", length = AppConstants.TOKEN_TOTAL_LENGTH)
    private String tokenId;
    // ... 其他字段和 Getter/Setter
}
```

### 3.3 `TokenRepository` 接口

创建 `TokenRepository` 接口，继承 `JpaRepository`，提供基本的 CRUD 操作和自定义查询方法，如 `existsByTokenId` 和 `findByAqisoBatchId`。

```java
public interface TokenRepository extends JpaRepository<Token, String> {
    boolean existsByTokenId(String tokenId);
    List<Token> findByAqisoBatchId(String aqisoBatchId);
}
```

### 3.4 `TokenGeneratorService` 接口与 `TokenGeneratorServiceImpl` 实现

定义 `TokenGeneratorService` 接口，包含 `generateBatch` 和 `exportBatch` 方法。`TokenGeneratorServiceImpl` 实现了这些方法。

*   **`generateBatch` 方法**: 
    *   生成批次 ID (`aqisoBatchId`)。
    *   循环生成指定数量的卡密，每个卡密通过 `generateUniqueToken` 方法确保唯一性。
    *   将生成的卡密保存到数据库。

*   **`generateUniqueToken` 方法**: 
    *   使用 `SecureRandom` 和 `AppConstants.TOKEN_CHARSET` 生成随机字符段。
    *   拼接前缀和随机段，形成 `RFZJ-XXXX-XXXX-XXXX` 格式的卡密。
    *   通过 `tokenRepository.existsByTokenId` 检查唯一性，如果重复则重新生成，直到唯一。

*   **`exportBatch` 方法**: 
    *   根据 `aqisoBatchId` 从数据库查询所有卡密。
    *   将查询到的卡密 `tokenId` 拼接成纯文本字符串，每行一个卡密。
